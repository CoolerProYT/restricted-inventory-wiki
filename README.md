# RestrictedInventory wiki

Documentation for RestrictedInventory, built with [VitePress](https://vitepress.dev/).

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run docs:dev
```

Build and preview the production site:

```bash
npm run docs:build
npm run docs:preview
```

All content pages live in this repository root. Site configuration and theme files live in `.vitepress/`.
